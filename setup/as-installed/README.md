# As installed

This folder holds the exact copy of each download as it was when it was installed or last updated, saved as `<name>.tar.gz`. You can leave it alone.

When you ask Claude to "get the latest version", it compares 3 things: this copy, your folder as it is now, and the new version. That is how it tells what you changed from what the kit changed, so your own work is never overwritten. Claude replaces the copy here after each update.

The files in this folder stay on your computer. They are not part of the kit that other people download.
