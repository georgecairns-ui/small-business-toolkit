# Setup

Read `START-HERE.md` in this folder and follow it, starting from the first unticked step in `setup/progress.md`. If they asked for one tool, run just that tool's part of `START-HERE.md` (Part 2), skipping anything `setup/progress.md`, `context/` and the tool data files already answer. If steps 1 and 2 in `setup/progress.md` aren't ticked, run Part 1 from its first unticked step first, and say so in one line. Everything you need is in `START-HERE.md` and the step files in `setup/`.
