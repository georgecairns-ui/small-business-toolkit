# Clients

One folder per client or customer, named after them (for example `Marlow Dental`). Inside: their proposals, contracts, meeting notes and work. Claude files meeting notes here as `YYYY-MM-DD Meeting with X.md`.

Naming: start file names with the date, `YYYY-MM-DD short description`, so they sort in order. Claude follows this when it files things for you (see `.claude/skills/file-it`).
