# Files

Your business documents, in numbered folders so they always sort the same way. Each folder has a short README saying what belongs in it. Claude suggests where things go (see `.claude/skills/file-it`) and only moves anything once you agree.

| Folder | For |
|---|---|
| `01-admin` | Company documents, insurance, legal, policies, licences and registrations |
| `02-clients` | One folder per client or customer, named after them (for example `Marlow Dental`) |
| `03-sales` | Leads, enquiries, proposals and quotes that haven't become clients yet, and your price lists |
| `04-marketing` | Brand files, website copy, social media posts, campaigns, photos |
| `05-finance` | Invoices, receipts, bank statements, tax and VAT, payroll |
| `06-operations` | How things get done: processes, checklists, suppliers, equipment, anything you'd hand to someone new |
| `07-team` | People who work with you: contracts, rotas, training, holidays |
| `08-projects` | Anything with a start and an end that isn't a single client: a new website, a product launch, a move |
| `99-archive` | Old things worth keeping |

Change the folders to suit your business: ask Claude, for example "add a folder for stock" or "call clients customers".
