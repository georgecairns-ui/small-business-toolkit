# Skills to upload

During setup, Claude learns how your business works and writes you your own skills: saved instructions for jobs like quoting, replying to new enquiries and welcoming a new client, using your real services, prices and tone.

They already work in Claude Code in this folder. The files here are the same skills, packed up so you can add them to Claude itself and use them in every conversation, including the Claude app on your phone.

## How to add them to Claude

1. Open Claude (claude.ai or the Claude app).
2. Go to **Customize**, then **Skills**.
3. Press **+**, then **Create skill**, then **Upload a skill**, and choose one of the `.zip` files in this folder.
4. Repeat for each file.

Skills need a paid Claude plan with code execution switched on (in **Settings**, under **Capabilities**).

If the menus look different, ask Claude: "Where do I upload a skill?"
