# Sage: not supported yet

Money View OS can't connect to Sage yet. There is no Claude connection for Sage that we can verify, and Money View works only through a live connection to the accounts app. It does not read exports, spreadsheets or reports saved into a folder.

If the person uses Sage, follow the "not supported yet" paragraph in `setup/money-01-your-accounts.md`: say it in one plain paragraph, leave Money View's accounts step unticked and stop. Don't set anything up, don't suggest a workaround, and don't ask them to export anything.
